# Flandre Android 拍题预览版

原生 Java + Android SDK，无额外移动框架或运行库。Android 8.0（API 26）及以上；当前版本 `0.1.0-preview.1`，编译目标 Android 15（API 35）。只连接项目已确认的 CloudBase 上海环境，不包含管理员密钥。

下载：在 [GitHub v0.4.0 预览版](https://github.com/flandre0605/flandre-notebook/releases/tag/v0.4.0-preview.1) 中选择 `Flandre-Android-0.1.0-preview.1.apk`。该发布同时包含电脑端 `0.4.0-preview.1` 免安装包。

## 使用

1. 电脑先安装/解压 `0.4.0-preview.1`，原账号题库保持原路径。当前上海环境已完成 004、005 部署，无需重复执行。其他新环境须先执行 004，再在“手机待整理”复制 **005** 脚本执行一次。
2. 把 `dist/Flandre-Android-0.1.0-preview.1.apk` 传到安卓手机，允许当前传输应用安装该预览包。
3. 手机登录与电脑相同的普通账号。拍照或选图，拖动框选题目，填写可选备注，保存到上传队列。
4. 联网后点击“上传全部待传图片”。上传失败保留原任务编号、原图和裁剪图，重新登录或重启后仍可手动重试。
5. 电脑打开“手机待整理”，点击“接收手机图片”→“打开并整理”。模型返回草稿后核对确认，才创建正式题目。
6. 再接收一次发送收录回执；电脑“账号与同步”同步正式题目。手机刷新处理状态，或更新“我的题目”查看电脑整理的题目。

## 当前范围

- 用户名密码登录；密码和会话仅在内存，设备标识及上次用户名留在本机。退出/重启重新联网登录；已保存队列在重新登录同一账号后恢复。
- 调用系统相机和图片选择器，无全相册读取权限、无相机权限申请；相机仅获授权访问随机临时输出 URI。图片拷贝进应用私有目录，不依赖相册 URI 后续可读。
- 保留最多 20 MB 的 PNG/JPEG/WEBP 原文件，按 EXIF 方向生成预览；在最长边不超过 2048 像素的解码预览上框选并生成 JPEG 裁剪图。建议靠近单题拍摄，细字仍可在电脑查看完整原图。
- 图片及任务按用户编号分别保存。没有后台自动上传；所有网络工作在单独线程执行，进行中的任务禁止界面切换账号。系统结束进程后可重试已完成本机保存的任务。
- 原图/裁剪图先上传到私有不可覆盖路径，下载对比原字节后再提交待整理记录。服务端 UUID 与不可变内容去重；提交成功但回执丢失时重试同一 UUID，不创建新记录。
- 手机显示本机队列及云端收录状态，缓存正式题目的文本、选项、答案、解析和笔记供查看。尚无公式排版、正式题目原图查看、掌握状态写回、手机 AI 识题、注册/找回密码、iOS 或应用商店发布。
- 题目快照缓存上限 1000 项、8 MB；处理状态快照上限 5000 项。原图暂不自动删除，卸载会清除手机私有数据；预览包升级使用同一开发签名时可覆盖安装。
- 同一待整理照片请在一台电脑上核对。接收到其他电脑已处理状态后会阻止旧草稿重复收录，但尚无跨电脑编辑锁；同时离线核对同一照片仍可能在不同电脑各收录一次。

## 构建与验证

安装官方 Android SDK 的 `platforms;android-35` 和 `build-tools;35.0.0`，使用 JDK 17：

```powershell
python scripts/build_android.py --sdk <SDK目录> --java-home <JDK目录> --checks
```

使用官方 AAPT2、javac、D8、zipalign 和 apksigner 构建。输出正式预览 APK 至 `dist/`；仅在 `build/` 生成并保留开发签名，不提交密钥。正式商店发行需要独立的生产签名及发布配置。

`--checks` 同时构建 `build/android-preview/checks/checks.apk`。在独立模拟器安装两个 APK 后执行：

```powershell
adb -s <测试设备> shell am instrument -w com.flandre.notebook.checks/com.flandre.notebook.NativeChecks
```
